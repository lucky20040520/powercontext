# 模型清单：来源、版本、SHA-256、体积与量化说明

> 所有模型均为**可公开获取的开源模型**，通过 `scripts/prepare_models.py` 下载并校验。
> 下载源默认 `hf-mirror.com`（Hugging Face 国内镜像），可用环境变量 `HF_ENDPOINT` 覆盖为 `https://huggingface.co`。
> 结构化的 SHA-256 清单文件：`docs/模型清单.json`（prepare 脚本自动生成）。

## 1. 模型来源与版本

| 模型目录名 | HuggingFace 仓库 | 原模型作者 | 说明 |
|---|---|---|---|
| `bge-small-zh-v1.5` | `Xenova/bge-small-zh-v1.5` | BAAI（北京智源） | BAAI/bge-small-zh-v1.5 的 ONNX 转换版（Xenova，transformers.js 生态），中文语义向量，512 维 |
| `all-MiniLM-L6-v2` | `Xenova/all-MiniLM-L6-v2` | sentence-transformers（UKPLab） | all-MiniLM-L6-v2 的 ONNX 转换版（Xenova），英文语义向量，384 维，与 seekdb 官方示例同款 |

- 上游开源协议：两模型上游均为 Apache-2.0。
- 转换版由 Xenova 发布（transformers.js 官方推荐转换），onnx 目录下的模型文件与 tokenizer 配套完整。

## 2. 量化方案

| 精度 | 前端 dtype | 模型文件 | 说明 |
|---|---|---|---|
| FP32（基线） | `fp32` | `onnx/model.onnx` | 32 位浮点，质量基线 |
| FP16 | `fp16` | `onnx/model_fp16.onnx` | 16 位半精度，官方 ONNX 变体；WebGPU 后端原生半精度算子 |
| INT8（Q8） | `q8` | `onnx/model_quantized.onnx` | 官方 Q8 动态量化变体；体积最小，WASM 下实测质量无损 |

量化采用**模型官方发布的 ONNX 变体**（Xenova 仓库内既有文件），不对权重做二次量化，保证可复现、可审计；量化前后检索质量对比见 `docs/技术说明.md` 与 `docs/验证记录.md`。

## 4. 每个变体目录的完整文件（Transformers.js 加载要求）

```
models/<模型>/<精度>/
├── config.json
├── tokenizer.json
├── tokenizer_config.json
├── special_tokens_map.json
├── vocab.txt
└── onnx/
    ├── model.onnx            # fp32
    ├── model_fp16.onnx       # fp16
    └── model_quantized.onnx  # int8
```

## 5. 重新生成

```bash
python scripts/prepare_models.py                      # 全部
python scripts/prepare_models.py --model bge-small-zh-v1.5 --variant fp16   # 单模型单档
HF_ENDPOINT=https://huggingface.co python scripts/prepare_models.py --force # 换源强制重下
```
