## 3. 全矩阵评测（12 组，K=5，热查询重复 3 次取中位数）

### 3.1 检索质量（Recall@5 / nDCG@5）

| 模型 | 精度 | 后端 | 混合 Recall/nDCG | 向量 Recall/nDCG |
|---|---|---|---|---|
| bge（中文 72 篇/20 查询） | FP32 | WebGPU | **95.0% / 92.8%** | 82.5% / 81.0% |
| bge | FP16 | WebGPU | 92.5% / 91.3% | 82.5% / 80.8% |
| bge | INT8(Q8) | WebGPU | 92.5% / 89.2% | **12.5% / 10.2%** |
| bge | FP32 | WASM | **95.0% / 92.8%** | 82.5% / 81.0% |
| bge | FP16 | WASM | **95.0% / 92.8%** | 82.5% / 81.0% |
| bge | INT8(Q8) | WASM | **95.0% / 92.8%** | 82.5% / 81.0% |
| mini（英文 24 篇/10 查询） | FP32 | WebGPU | 90.0% / 78.9% | 90.0% / 92.3% |
| mini | FP16 | WebGPU | 90.0% / 78.9% | 90.0% / 92.3% |
| mini | INT8(Q8) | WebGPU | 80.0% / 72.3% | **5.0% / 3.9%** |
| mini | FP32 | WASM | 90.0% / 78.9% | 90.0% / 92.3% |
| mini | FP16 | WASM | 90.0% / 78.9% | 90.0% / 92.3% |
| mini | INT8(Q8) | WASM | 90.0% / 78.2% | 90.0% / 92.3% |

**质量结论（实测）**：
- FP16 两后端均与 FP32 基线基本一致（中文混合 92.5%~95%，英文持平）。
- INT8(Q8) + **WASM 几乎无损**（中文 95.0%/92.8% 与基线完全一致；英文 nDCG 78.2% vs 78.9%，-0.7pp）。
- INT8(Q8) + **WebGPU 纯向量路断崖式退化**（中文 82.5%→12.5%，英文 90%→5.0%）：Q8 量化模型的部分算子在该环境回退到非 GPU 执行，embedding 数值精度受损。**混合检索仍保持 92.5% / 80.0%**——全文路兜底，RRF 融合价值被直接验证。
- 推荐组合：FP16 + WebGPU（综合最优）；低配/无 GPU 环境：INT8 + WASM（质量无损、体积最小）。

### 3.2 分阶段性能（中文集，热查询中位数）

| 配置 | 向量化吞吐 | 向量化 72 篇 | 写入 | 索引刷新 | 查询向量化 | seekdb 检索 | 端到端查询 |
|---|---|---|---|---|---|---|---|
| FP32 + WebGPU | 85.4 doc/s | 844 ms | 636 ms | 213 ms | 9 ms | 6 ms | 19 ms |
| FP16 + WebGPU | 94.0 doc/s | 766 ms | 503 ms | 303 ms | 8 ms | 6 ms | 17 ms |
| INT8 + WebGPU | 19.9 doc/s | 3.61 s | 831 ms | 213 ms | 77 ms | 7 ms | 86 ms |
| FP32 + WASM | 13.6 doc/s | 5.28 s | 653 ms | 312 ms | 18 ms | 6 ms | 26 ms |
| FP16 + WASM | 12.7 doc/s | 5.65 s | 666 ms | 241 ms | 38 ms | 6 ms | 47 ms |
| INT8 + WASM | 22.7 doc/s | 3.17 s | 669 ms | 316 ms | 13 ms | 6 ms | 22 ms |

**性能结论（实测）**：WebGPU 相对 WASM 向量化吞吐提升约 4~7 倍；seekdb 混合检索延迟稳定 4~7 ms；INT8 + WebGPU 因算子回退反而最慢（19.9 doc/s），INT8 + WASM 为 22.7 doc/s 且质量无损。英文集数据（24 篇，吞吐最高 142.5 doc/s WebGPU）见 `data/eval-log-final.json`。
