# 运行说明

## 环境要求

- Python 3.8+（纯标准库，无第三方依赖）；
- Windows / Linux / macOS 均可；
- 可选：本地或远程 PowerContext Server（不启动时自动降级为纯本地模式）。

## 复现步骤

### 1. 单元测试（19 个用例）

```powershell
# 在 minimax/ 目录下
python tests/run_all.py
# 或
python -m unittest discover -s tests
```

覆盖：

- `test_registry.py`：规格登记、版本演进（supersede）、退役、决策级联失效、序列化；
- `test_validity.py`：VALID / STALE / INVALID 三态判定、符号提取；
- `test_assembly.py`：任务上下文组装（只含 active 规格）、无关任务警示、失效决策；
- `test_handoff.py`：快照导出/导入往返、交接后上下文一致、磁盘对账。

### 2. 端到端场景演示

```powershell
python scenario_demo.py
```

脚本会**真实读写** `demo_project/src/order_discount.py` 与
`demo_project/tests/test_order_discount.py`，模拟五阶段演进
（v1.0 → 修复 v1.1 → 规格升级 v2.0 → 契约变更 → 交接），
全部断言通过后把文件恢复为 v2.0 当前版并打印“全部场景验证通过”。

### 3. 示例项目自身测试

```powershell
python demo_project/tests/test_order_discount.py
```

确认 v2.0 实现（阶梯满减 + 折扣码叠加 + 非正数返回 0.0）与 v2 测试一致。

## 接入 AI 开发助手（可选）

将本目录的 `SKILL.md` 安装到助手的技能目录，助手即可遵循其规约调用
`sdd_context` 包完成：登记规格 → 组装任务上下文 → 判定验证有效性 → 交接。

```python
# 最小示例
from sdd_context import SpecRegistry, ValidityEngine, ContextAssembler, HandoffManager

reg = SpecRegistry()
reg.register_spec("order-contract", "1.0.0", SpecKind.CONTRACT,
                  "### 函数 `compute_discount(amount) -> float`",
                  linked_files=["src/order.py"], linked_tests=["tests/test_order.py"])
reg.record_code("src/order.py", HandoffManager.digest_file("src/order.py"))
reg.register_test("tests/test_order.py", spec_ref="order-contract",
                  covered_files=["src/order.py"], last_status="passed")

ctx = ContextAssembler(reg, ValidityEngine(reg)).assemble(
    "实现订单折扣", current_hashes=HandoffManager.current_hashes(["src/order.py"]))
print(assembler.render_prompt(ctx))   # 可直接注入 AI 助手的上下文
```

## 与 PowerContext Server 对接（可选）

```powershell
# 设置环境变量（PowerShell 示例）
$env:POWERCONTEXT_SERVER_URL   = "http://127.0.0.1:8000"
$env:POWERCONTEXT_SERVER_AUTH_TOKEN = "your-token"
$env:POWERCONTEXT_SCOPE_ID     = "your-scope"

# 桥接层自动生效：规格/失效决策写入记忆，支持跨会话召回
from sdd_context import PowerContextBridge
bridge = PowerContextBridge()
print(bridge.is_available())          # False 时自动降级，主流程不受影响
```
