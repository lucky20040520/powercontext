# PDF 全文解析与证据页检索改动说明

日期：2026-10-29。开发分支：`feat/pdf-layout-fallback`。

本次改动针对财报 PDF 的词项边界、损坏字符映射和重复绘制问题，采用“默认提取优先、风险触发候选、完整性校验后选择”的解析策略。对七页边界问题实施通用修复后，完整重解析 84 份、12,013 页，独立数量失败由 7 页降至 2 页。剩余两页为 MGM 页码与文件编号的参考边界争议，保留真实文字并等待官方冻结参考核验。证据召回和全文 F1 仍各有 14 条失败，没有新增标注失败，尚未全部满足质量门槛。

## 1. 改动目标与约束

无条件优先使用 layout 会引入几类问题：表格单元格中的数字被连在一起、非空页面漏掉 Form 中的图表文字，以及原本完整的单词被拆开。另一方面，默认模式也存在单字母碎片和词内断行，因此需要根据 PDF 自身的信息选择结果。

本次实现遵守以下约束：

- 评分公式及阈值保持不变。
- 生产代码不根据文档名、物理页码或参考答案选择解析结果。
- 不通过删除真实文字来满足词项数量检查。
- 原始 PDF 字节、文件摘要、物理页编号和 Source 身份规则保持不变。
- 参考词项和 FinanceBench 标注只用于解析结束后的独立离线评估。

## 2. 生产解析流程

```text
原始 PDF
  → 校验并按顺序读取所有物理页
  → 使用默认模式提取正文
  → 按 Unicode 定义展开字母连字
  → 有明确 PDF ActualText 依据时修复 NUL 字符映射
  → 有重复风险时检查并去除可证明的同位置重复绘制
  → 计算默认文本的碎片和重复风险
      ├─ 风险不明显：保留默认结果
      └─ 风险明显或稀疏碎片经坐标确认：尝试 layout
          ├─ 碎片改善且完整性检查通过：采用 layout
          ├─ layout 数字分组失真、坐标候选完整且改善：采用坐标候选
          └─ 无候选通过检查：保留默认结果
  → 压缩连续空格和制表符，保留换行及完整正文
  → 返回全部物理页
```

候选比较以完成 PDF 元数据修复、已证明的重复绘制处理后的默认文本为基准。元数据恢复和去重各自需要独立依据，不通过候选评分猜测应该增删哪些字符。

合法空白页仍返回空文本；损坏或无法完整解析的文档仍整体失败，不返回部分成功页面。扫描图像不进行 OCR。

### 2.1 默认文本的风险指标

| 指标 | 计算方式或用途 |
| --- | --- |
| 文本长度 | 提取结果的字符数 |
| 非空白字符数 | 去除空白后的字符数 |
| 异常短词比例 | 长度不超过 2 的英文字母词项，排除常见短词后，占英文字母词项总数的比例 |
| 异常单字母比例 | 排除 `a`、`i` 后，单字母词项占英文字母词项总数的比例 |
| 重复文本风险 | 去除空白后，统计重复的 24 字符窗口；对完整短文本重复两遍的情况补充检测 |
| 异常短碎片断行数 | 换行两侧存在异常短碎片的位置数，用于发现被长正文或表格内容稀释的局部问题 |

满足以下任一条件时才尝试 layout：

1. 异常单字母至少 4 个，且比例不低于 3.5%。
2. 异常短词至少 8 个，且比例不低于 10%。
3. 紧邻异常短碎片的断行至少 3 处。
4. 存在异常短词和词内断行，且完整的坐标候选独立确认碎片减少；适用于稀疏页面或正文中的局部断词。

这些是解析模式选择的启发式参数，不是比赛评分阈值。重复风险的计算不依赖词间空格或换行，避免正常修复字母间距后，把已有的重复表头误判为新增重复。

### 2.2 layout 候选的采用条件

候选必须同时满足：

- 正文非空。
- 全部非空白字符的频次与基准一致，包括百分号、负号及尚未恢复的 NUL。
- 能够完整解释水平 Identity-H 坐标时，候选数字及频次必须与实际数字分组一致；不支持坐标时，继续保留默认结果中含连续多位数字的完整数值及其频次。
- 重复风险相对基准的增加不超过 0.02。
- 异常单字母数量下降且异常短词不增加；或者异常短词至少减少 2 个且异常单字母不增加；或者异常短词断行和短词数量同时下降且单字母不增加。

候选间比较采用保留字符总量下的碎片数量，不再用各自变化的词项总量作分母。这样可以避免修复合词后总词数减少，反而把更好的候选判为比例退步。

坐标辅助从字体中明确映射的普通空格或不换行空格读取正字宽，不改写这些字形。存在两类空格时采用较小的已声明正字宽作为保守间距尺度。正文中的真实不换行空格继续保留，不能根据标注的连写词全局删除。

数字边界重建只处理空格或制表符造成的拆分，必须能唯一定位，且合并前后的数字频次差与坐标候选一致。不同列、不同基线及不同字号的数字不据数量目标拼接。layout 将脚注插入数字内部、无法通过空白修复时，只有完整坐标候选本身改善碎片并保留全部字符才使用该候选，否则保留默认结果。

这些条件能够拒绝部分文字缺失、金融符号缺失和数字单元格粘连的候选，但不能证明所有阅读顺序及数字碎片边界都正确。

## 3. American Express 字符恢复

`AMERICANEXPRESS_2022_10K` 的部分嵌入字体将字形映射为 NUL，导致完整单词被拆成多个词项。原始 PDF 的标记内容同时提供了 `/ActualText`，明确说明对应字形的真实文字，例如 `ti`、`ft`、`tt`。

生产实现依据 PDF 自带标记恢复字符，不使用词表猜测，也不把所有 NUL 替换成固定字符串。修复仅适用于满足以下条件的 Identity-H 字体：

- 字符在 `ToUnicode` 的 `bfchar` 条目中映射为 NUL。
- 每个替代标记覆盖一个字形。
- 该编码在当前页的所有出现位置均被标记覆盖，且替代文字完全一致。
- 不存在冲突或嵌套替代；页面不含 Form 或图形状态字体覆盖。

不满足条件时保留原始解释。实现通过复制页面资源及字体映射完成处理，不修改输入 PDF 字节。字母展示连字仅按 Unicode 定义展开，其他兼容字符不做整体 NFKC 转换。

| --- | ---: | ---: | ---: |
| 176 | 601 | 541 | 541 |
| 177 | 734 | 664 | 664 |
| 248 | 293 | 263 | 263 |
| 249 | 586 | 469 | 469 |

NIKE 的修复采用通用的精确重绘检测：只有同一文字对象内，字体字典、文字位置、文字状态和绘制内容相同，且后续位置重置保证删除不会影响后续文字推进时，才移除重复绘制。不同位置、字号、颜色或图形状态之间的相同文字不会因此被删除。

MGM 两页实际包含页码 `- 2 -` 和白色文件编号 `41086.01500`。独立参考将页码和编号连成了 `241086.01500`，而当前结果保留为 `2`、`41086`、`01500` 三个词项。因此两页是 3 对 2 的数量差异，不属于当前结果低于数量下限，也没有证据支持删除真实编号或拼接字符。

## 5. 坐标重建实验

新增 [pdf_fragment_experiment.py](../../../scripts/pdf_fragment_experiment.py)，独立保存并比较：

- 默认模式与 layout 模式的完整文本。
- 基于原始字符编码、CID 字体宽度、文字位置和水平间距重建的文本。
- 结合 PDF 自带 ActualText 恢复后的重建文本。
- 每个文字片段的编码、字体、起止坐标、空格宽度及与前一片段的间距。
- 全部词项及频次、异常单字母、NUL 数量，以及相对默认结果的缺失和额外词项。

运行方式：

```powershell
.venv/Scripts/python.exe scripts/pdf_fragment_experiment.py INPUT.pdf OUTPUT_DIR --pages 1 2
```

实验仅支持水平 Identity-H 字体，遇到不支持的字体、Form、旋转、倾斜或相关绘制操作时明确拒绝。它使用 pypdf 内部定位辅助接口。生产辅助模块 `_pdf_geometry.py` 采用同类原始 CID 字宽计算，仅在完整字符校验和风险判断通过时提供数字边界依据或受限回退候选，不把该实验脚本作为运行时依赖。实验和生产模块均不读取参考答案；相对 Poppler 的缺失词、额外词和频次由独立离线评估步骤生成。

## 6. 全量质量验证

数据为 FinanceBench 固定 revision `cc39aeb4afdf33909ee1412188bf89035950c2eb` 的 84 份完整公开报告，共 12,013 页。解析完成后，对 150 个公开问题对应的 189 条证据标注计算解析质量。

离线分词仍采用转小写后的 `[a-z]+|\d+`，保留词项频次，交集使用多重集合交集：

- 证据词项召回率 = 解析页与证据的交集词项数 / 证据词项数，要求每条不低于 0.95。
- 整页词项 F1 = 2 × 解析页与标注全文的交集词项数 / 两者词项总数，要求每条不低于 0.95。
- 每页词项数量要求保持参考值的 90%–110%。

| 失败项 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 页面词项数量检查 | 7 页 | 2 页 |
| 证据词项召回率 | 14 条 | 14 条 |
| 标注全文词项 F1 | 14 条 | 14 条 |

七页边界修复阶段相对于默认候选选择基线，没有新增标注失败，10 条标注的已通过指标进一步改善，507 页的输出发生变化。不能把指定页面的修复结果等同于所有质量指标通过；后续局部短词及不换行空格修复的完整结果见第 10 节。

对全部 12,013 页的独立检查确认，非空白字符频次与修改前一致，12,013 个唯一 Source 的身份及版本不变，并可通过公开 Source 定义逐页读回完整正文。这不等同于把全部页面重新写入数据库；数据库持久化、重启及 citation 由端到端测试验证。

## 9. 已持久化数据的使用注意事项

解析策略不会自动重写已有 Source 或 Memory，已有 citation 仍指向原有内容。页身份仍由文档 ID、原文件 SHA-256 和物理页码确定，不包含解析正文。

对同一 PDF 使用新解析策略时，应在新的 Scope 中重新摄取。向已有 Scope 的相同页身份提交不同正文，会产生身份冲突；不应通过覆盖历史正文或修改引用身份绕过该约束。

## 10. 证据词项召回与全文 F1 的根因修复

坐标辅助支持字体明确映射的不换行空格，并对局部异常短词断行先执行坐标确认。完整重解析 12,013 页后，重新计算全部 189 条标注的两项指标：3 条同时改善，其余 186 条不变，没有任何指标下降，也没有新增失败。253 页输出改变，全部页面非空白字符频次、Source 名称及版本不变。

剩余证据召回与全文 F1 失败仍各为 14 条；这些页面当前词频均与独立 Poppler 一致。按当前独立数量参考，12 条标注在满足数量约束时的理论 F1 上限低于 0.95，需核对官方冻结参考与标注词边界，不能靠删除空白或正文修补。
