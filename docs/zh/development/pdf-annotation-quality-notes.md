# PDF 证据词项召回与全文 F1：根因修复说明

开发分支：`feat/pdf-layout-fallback`。本轮重新解析全部 84 份、12,013 个物理页，并重新计算全部 189 条公开标注的证据词项召回和全文词项 F1，共 378 项结果。

3 条标注的两项指标同时提高，全部 189 条均未下降，没有新增失败。失败数仍分别为 14 条。当前剩余 14 条对应页面的词频均与独立 Poppler 参考一致，存在需要与官方冻结参考核对的标注边界差异，不能宣称已全部通过。

## 1. 根因与实际修复

### 字符映射

检查原 PDF 的 ToUnicode、字体编码、内容流和 ActualText。14 张问题页的现有输出没有未解码 NUL 或 Unicode 替代字符，内容流没有提供可用于恢复的 ActualText，因此未新增字符替换或猜测。

两张 MGM 2020 页面将词间空格映射为 U+00A0 不换行空格，原始 CID 字宽为正值。坐标辅助现在可以使用普通空格或不换行空格的已声明正字宽进行度量；存在多个正字宽时使用较小值作为保守间距尺度。该处理保留原来的 Unicode 空白，不把它改成空串，也不根据标注连写词删除分隔符。

### 单词拆分与合并

默认提取仍是基础。局部异常短词紧邻断行时，先尝试完整、受支持的 CID 坐标解释；只有坐标候选本身改善碎片且完整保留字符，才允许尝试 layout。这样可修复被较长正文稀释的局部断词，无需降低全页碎片比例门槛。

MGM 两页中的 INTERNATIONAL 被拆开，SUBSIDIARIES 与下一行的 CONSOLIDATED 粘连，部分短词也出现断行。原始页图与实际基线支持将这些边界恢复。重建没有添加人工词项，也没有删除标题或表格行。

坐标解释仍只支持受限的水平 Identity-H 文本。遇到不支持的字体、Form、旋转、倾斜和相关操作时，放弃该辅助依据并继续原提取路径。完整字符校验、数字分组校验和候选改善条件仍然生效。

### 金融数字与符号

负号、百分号、小数点及其他非空白字符的全页频次与修改前保持一致。数字边界必须符合原始 CID 字宽与坐标分组，不能仅凭词项数量选择。

全部页面中有 84 页的完整数字边界发生变化。独立比较其数字词频多重集合，84 页全部改善，80 页达到与独立参考完全一致，没有数字指标下降。这里的数字审计是离线验证，不参与生产候选选择。

### 重复绘制

14 页在 0.01 pt 容差下没有可删除的重复字形。Corning 两页在 1 pt 容差下检测到的疑似重复都是空白字形，实际纵向位置相差约 0.671 pt；不能据此认定为可安全删除的同位置重绘。本轮未放宽去重条件，也未删除这些文字或空白。

## 3. 标注与独立参考的边界核验

12 条原失败标注的现有解析词频原本就与独立 Poppler 完全一致；两张 MGM 页修复后也达到一致。标注全文却会将原 PDF 中用真实空白分隔的文字连写，例如原页可见的 `Cost of goods sold` 对应标注词项 `Costofgoodssold`。部分标题空白在字体中被映射为换行，标注同样发生连写。

原图、原始字符坐标、字体、Unicode 空白码位和内容流已经保存。这里只将其标记为边界差异，不能据此默认断定解析器或标注必然错误。生产代码不读取标注，也不为提高交集而拼接这些词语。

按当前独立数量参考，有 12 条标注无法同时满足数量下限和 F1 门槛。令参考词数为 R、标注词数为 G，数量允许范围为 L=ceil(0.9R)、U=floor(1.1R)。即使忽略实际内容约束，最佳交集也不能超过 min(A,G)，因此 F1 上限是 `2×min(A,G)/(A+G)`，其中 A 取范围内最接近 G 的整数。

例如 Best Buy 2017 第 56 页的独立参考 R=291、标注 G=199，数量要求 A≥262，即使标注所有词项全部匹配，F1 也至多为 `398/461≈0.863341`。这说明当前独立参考与该标注组合存在兼容性疑点；独立 Poppler 不是官方冻结词数，不能由此宣称官方评分合同冲突。

## 4. 完整性、身份与测试

- 全部 12,013 页的原始 SHA256、物理页顺序和页数均已核对。253 页输出改变，但所有页面的非空白字符频次与修改前完全相同。
- 全部 12,013 个唯一 Source 的名称及版本保持不变，逐页通过公开 Source 定义读回完整正文。
- 固定 Python 3.12.14 / pypdf 6.19.0、1 CPU / 2 GiB、无网络环境：68 项解析、真实持久化、幂等、重启、精确 citation 和公开验收测试通过。
- 本机 Python 3.12 / pypdf 6.21.2：62 项回归通过。相关文件 Ruff、Linux 平台 ty 和 `git diff --check` 通过。
- 全量解析使用无网络容器、3 个进程、4 CPU / 4 GiB；只挂载 PDF 输入、冻结源码、推理脚本和独立输出目录，没有标注或参考挂载。不能据此宣称满足 1 CPU 性能预算。

本轮没有将全部 12,013 页重新写入数据库，也没有重跑全部 150 题的 evidence-page Recall@20。数据库行为由真实端到端回归验证。隐藏组和正式比赛子集未验证。两张 MGM 稀疏页的页码/文件编号参考边界争议继续保留。
