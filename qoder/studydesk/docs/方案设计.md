# 研习台 StudyDesk —— 方案设计

> 数据库大赛 · Qoder 赛题：用 Qoder 做一个让学习、科研和工作更高效的项目
> 项目目录：`qoder/studydesk/`（基于 `2026-competition-ecosystem` 分支）

## 1. 一句话

研习台是一个本地运行的"记忆 + 检索"双引擎提效助手：用 **seekdb** 做知识库混合检索（论文/笔记/实验记录语义定位），用 **PowerContext** 做长期记忆（进度、决策、约束、薄弱点跨会话复用），自动把两者组合成**周报草稿**和**复习清单**，并提供 Web 界面 + CLI 两种入口。

## 2. 解决的痛点（真实场景）

| 痛点 | 现状 | 研习台方案 |
| --- | --- | --- |
| 资料难检索 | 几十篇论文/笔记散落各处，"以前看过一段关于 X 的论述"要翻半天 | 导入 seekdb，语义 + 关键词混合检索，一条命令/一次搜索返回相关段落与出处 |
| 进度难回忆 | 跨会话忘了上周做到哪、确认过什么决定 | PowerContext 长期记忆：status / decision / constraint 三类原子记忆，跨会话召回 |
| 周报/复盘费时 | 从聊天记录、任务记录里一条条拼 | 从 PowerContext 召回本周进展 + seekdb 检索相关资料，自动生成周报草稿 |

## 3. 技术选型与分工（题目要求"指定技术实际发挥作用"）

| 技术 | 分工（实际作用） |
| --- | --- |
| **seekdb**（必选之一） | 知识库的**存储与混合检索**：文档分块后写入向量索引 + 全文索引，`hybridSearch` 做全文 + 向量 RRF 融合检索；`query` 做纯语义检索。检索结果直接用于"资料问答"与"周报相关资料段落" |
| **PowerContext**（必选之一） | **长期记忆**：通过 HTTP API 把用户的学习/科研/工作进展、决策、约束写入 `atomic-memory`，跨会话 `search`/`list` 召回；周报与复习清单的数据来源 |
| transformers.js（辅助） | 本地向量化：bge-small-zh-v1.5（q8），离线推理、无外部 API；仅负责把文本转成向量交给 seekdb |
| Node.js 22 + Express | 应用运行时：CLI + Web UI + API 编排两个引擎 |

> 同时使用两者，分工明确：**seekdb 管"资料"，PowerContext 管"人"**。

## 4. 功能清单

1. **资料导入** `study import <file|dir>`：读取 md/txt，按段落分块 → 向量化 → 写入 seekdb（元数据含来源文件名）
2. **混合检索** `study search <关键词>`：seekdb 全文 + 向量混合检索，返回相关段落 + 来源
3. **记忆记录** `study record --kind status "文本"`：写入 PowerContext 原子记忆（kind ∈ status/decision/constraint/weakpoint）
4. **记忆召回** `study recall <话题>`：从 PowerContext 召回相关记忆
5. **周报生成** `study weekly [--since 本周]`：召回本周 status/decision 记忆 + 检索相关资料段落 → 输出周报草稿
6. **复习清单** `study review`：召回 weakpoint 记忆 + 检索对应资料 → 生成复习清单
7. **Web 界面** `study web`：浏览器可视化完成以上所有操作

## 5. 数据流

```
导入: 文件 → 分块 → transformers.js 向量化 ─┐
                                           ├─→ seekdb(知识库, 向量+全文索引)
检索: 查询词 → 向量化 ─────────────────────┘   → hybridSearch → 段落+出处
记录: 进展/决策/约束/薄弱点 ──→ PowerContext(原子记忆, scope 隔离)
召回: 话题/本周 ──→ PowerContext search/list → 记忆列表
周报: 记忆召回 + 资料检索 → 模板组装 → 周报草稿
```

## 7. 关键技术决策（已在 spike 验证）

- seekdb 嵌入式（Windows）：npm `seekdb@1.4.0` + `@seekdb/js-bindings`（win32-x64 已缓存），`SeekdbAdminClient` 建库 + `SeekdbClient` 建集合（hnsw 512 维 cosine + ik 全文 smart 分词），显式 embeddings 写入，`query`/`hybridSearch`/`refresh_index`/`count` 全部实测通过。
- 向量化：`@huggingface/transformers` pipeline feature-extraction，模型 `Xenova/bge-small-zh-v1.5`（q8，512 维），远程源 `hf-mirror.com`，缓存目录可配置（默认项目内 `.cache/`，可覆盖到 D 盘）。
- PowerContext：本地 `powercontext` CLI（1.4.2.dev21，uv tool 安装），`config init --template` 生成免模型配置（基础记忆模式），`server run --env-file .env` 启动；HTTP API：POST `/v1/scopes` 建 scope、POST `/v1/scopes/{id}/artifacts` 写记忆（family=atomic-memory）、POST `/v1/atomic-memory/search|list` 召回。中文 UTF-8 读写实测通过。
- 端口：PowerContext 默认 8000；研习台 Web 默认 8787（避免冲突）。

## 8. 验证样例（评审入口）

`scripts/scenario-demo.mjs` 一键执行并断言：
1. 准备演示数据（5 篇资料 + 3 条记忆，脚本内置，可重复）
2. 语义检索：查询"数据库索引结构"应命中"索引结构"相关资料（断言首条命中）
3. 混合检索：全文"向量" + 语义"论文调研"融合结果非空
4. 记忆写入 + 召回：写入"数学复习进度"，search 返回该记忆
5. 周报生成：基于记忆召回 + 资料检索生成周报草稿，断言包含本周进展
6. 输出结构化 JSON 记录（检索记录/记忆读写记录 = 技术作用凭证）
