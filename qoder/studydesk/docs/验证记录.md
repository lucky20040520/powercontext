| seekdb | 知识库存储与混合检索：导入资料向量化后写入（hnsw 512 维 + ik 全文）；语义检索 `search`、`hybridSearch` 融合全文与向量；周报/复习清单从知识库拉取相关资料段落 | `data/scenario-result.json` 的 seekdb 段（available=true）+ §2.1 真实输出 |

## 4. 工程鲁棒性设计（对应本环境的实际问题）

- **子进程探测**：seekdb 嵌入式是进程内原生插件，加载异常会卡死主线程；项目改为先由子进程探测（15s 超时），确认可用后才在本进程加载。
- **自愈与降级**：数据目录被残留锁污染时自动整目录重建重试一次；仍失败则降级为 PowerContext 资料存储（纯 HTTP），全部功能可用。
- **PowerContext scope 固定**：scope id 写入 `.env`，避免每次进程各自建新 scope 导致数据"丢失"。
- **已知边界**：seekdb 嵌入式为本地单进程引擎，异常退出的残留进程会短暂锁住数据目录（重启机器或等待进程结束即可恢复；`npm run demo` 幂等可重复）；同一数据目录勿多进程并发。
