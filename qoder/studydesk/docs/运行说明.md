# 运行说明

## 1. 运行环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（macOS/Linux 亦兼容） |
| Node.js | ≥ 22（ESM 项目） |
| Python | ≥ 3.11（仅用于运行 PowerContext Server） |
| uv | ≥ 0.4（用于安装 PowerContext CLI，可选） |
| 内存 | ≥ 4 GB（向量化模型约占用数百 MB） |

## 2. 依赖安装

```bash
# 2.1 项目依赖（研习台）
cd qoder/studydesk
npm install          # 安装 seekdb@1.4.0、@huggingface/transformers、express

# 2.2 PowerContext（记忆服务）
uv tool install --force "powercontext[cli,server]==1.4.1"
```

> 首次运行向量化会自动下载模型 `Xenova/bge-small-zh-v1.5`（约 24 MB，q8 量化），
> 下载源为 hf-mirror.com（中国大陆可用）。可通过 `.env` 的 `STUDYDESK_EMBED_CACHE` 指定模型缓存目录（建议放到空间充足的盘，如 `D:/qoder-model-cache`）。

## 3. 启动 PowerContext Server（记忆服务）

```bash
cd <powercontext-工作目录>
powercontext config init --language zh --output .env --template --force
# 生成免模型配置：SQLite 存储、端口 8000、无需任何 API Key（基础记忆模式）
powercontext server run --env-file .env
# 看到 "Uvicorn running on http://127.0.0.1:8000" 即启动成功
```

可选：预先创建记忆空间并写入 .env：

```bash
powercontext scope create --title studydesk --summary "研习台记忆空间"
# 输出 scope id（scp_xxxx），复制到研习台 .env 的 POWERCONTEXT_SCOPE_ID
```

## 4. 配置研习台

```bash
cd qoder/studydesk
copy .env.example .env        # Windows
# 按需修改：
#   POWERCONTEXT_SERVER_URL=http://127.0.0.1:8000   （与 3 一致）
#   POWERCONTEXT_SCOPE_ID=                          （可留空，应用自动创建）
#   STUDYDESK_EMBED_CACHE=D:/qoder-model-cache      （模型缓存放 D 盘示例）
```

## 5. 准备演示数据并验证

```bash
npm run demo-data     # 导入 8 条演示资料 + 写入 5 条演示记忆
npm run demo          # 一键验证：检索/混合检索/记忆读写/周报生成，全部断言
# 输出 SCENARIO OK 即通过；结果明细写入 data/scenario-result.json
```

## 6. 使用

### CLI

```bash
node src/cli.js import ./docs/samples   # 导入资料目录
node src/cli.js search "数据库 索引结构"  # 语义检索
node src/cli.js hybrid "向量" "论文调研"   # 混合检索
node src/cli.js record --kind status "本周完成了 X"
node src/cli.js recall "数学 复习"
node src/cli.js weekly    # 周报草稿
node src/cli.js review    # 复习清单
node src/cli.js count
```

### Web 界面

```bash
npm run web     # 打开 http://127.0.0.1:8787
```

页面包含：资料导入、语义/混合检索、记忆记录与召回、周报与复习清单生成、系统状态。

## 7. 验证样例（评审复现路径）

1. `npm install`（依赖）
2. `powercontext server run --env-file .env`（PowerContext 服务，端口 8000）
3. `npm run demo-data && npm run demo`（一键验证，SCENARIO OK）
4. `npm run web` → 浏览器体验主要功能

## 8. 已知边界

- seekdb 嵌入式模式为本地单进程引擎（内部端口 2881）；异常退出的残留进程可能短暂锁住数据目录。项目已内置：子进程探测 → 失败自愈（重建数据目录重试一次）→ 自动降级为 PowerContext 资料存储（纯 HTTP，功能不变）。`npm run demo` 幂等，可随时重跑。
- 请勿在多个进程/终端中同时操作同一 seekdb 数据目录。
- PowerContext 基础记忆模式（免模型配置）下，召回使用文本匹配模式（`mode: text`）；若配置了 embedding 模型，召回自动升级为混合模式。
- 首次导入较慢（模型加载约 3~10 秒 + 逐批向量化）。
