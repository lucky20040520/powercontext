## 3. 调试（Qoder 参与）

- spike 阶段由 MainAgent 与本机实测定位：seekdb 嵌入式 Windows 绑定可用（`@seekdb/js-bindings` win32-x64）、pyseekdb 仅 Linux、PowerContext `config init` 交互确认阻塞（需喂 stdin）、PowerContext 中文写入需 UTF-8（Node fetch，PowerShell Invoke-RestMethod 会乱码）、scope 创建需 idempotency_key 而 artifact 写入禁止携带。
- 端到端调试发现并解决的环境问题（已固化为工程能力，见 `docs/验证记录.md` §4）：
  1. seekdb 原生插件异常退出会留下残留锁，导致后续打开报 "pid file locked" → 子进程探测 + 数据目录自愈重建 + 自动降级；
  2. PowerContext 每个新进程若不固定 scope 会各自建空 scope → scope id 写入 `.env`；
  3. listMemory 的 limit 上限 100 → 降级路径按上限取值。
